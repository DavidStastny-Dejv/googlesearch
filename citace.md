## Prompty a konzultace s AI

* **Prompt:** „Potřebuju poradit s tvorbou formulářové stránky a zkontrolovat menší část kódu, protože si nevím rady s některými prvky.“
  * **Výsledek:** Drobná pomoc a konzultace ohledně syntaxe vybraných formulářových prvků. Většinu kódu jsem napsal sám.
* **Prompt:** „Jak správně naklonovat repozitář z GitHubu do VS Code / Codespaces a jak vytvořit potřebné soubory?“
  * **Výsledek:** Podrobný návod na klonování přes Git příkazy a správné umístění souborů v adresáři.
* **Prompt:** „Jak upravit zarovnání a odsazení odkazu Obrázky vedle loga, aby to nebylo namačkané?“
  * **Výsledek:** Úprava CSS stylů pro čisté rozestupy a zarovnání v hlavičce.
